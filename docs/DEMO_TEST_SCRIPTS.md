## 1. כללי (General)

### 1.1 הצגת המערכת דרך סימן השאלה (?)
**מטרה:** להראות את מסך המידע/הסבר המובנה במערכת.

1. לאחר התחברות (בכל תפקיד), לחצו על סמל **? (סימן שאלה)** בסרגל העליון
2. עברו על ההסבר המותאם לתפקיד

**תוצאה צפויה:** נפתח חלון **מידע על המערכת** (SystemInfoModal) עם הסבר קצר על היכולות לפי התפקיד המחובר.

### 1.2 תמיכה נרחבת — זימון תור לכל סוגי המשתמשים
**מטרה:** להראות שאפשר לקבוע תור גם עבור **מזכירה, רופא ואדמין** (ולא רק מטופל "רגיל").

1. היכנסו כמזכירה → **קביעת תור**
2. בשלב בחירת המטופל, חפשו משתמש שהוא בעצם **מזכירה / רופא / אדמין**
3. הראו שהוא מופיע ברשימה וניתן לקבוע עבורו תור

**תוצאה צפויה:** לכל משתמש במערכת יש פרופיל מטופל, ולכן ניתן לזמן תור עבור כל תפקיד — לא רק עבור מטופלים.

### 1.3 שיוך למרפאה (Clinic Scoping)
**מטרה:** להסביר שרופא ומטופל משויכים למרפאה, וההרשאות מוגבלות לפי המרפאה.

1. הסבירו: כל **רופא** וכל **מטופל** משויכים ל**מרפאה**
2. הדגימו שמזכירה/רופא רואים ויכולים לקבוע תור **רק עבור רופאים באותה מרפאה**
3. הדגימו שרשימת המטופלים מציגה **רק מטופלים של אותה מרפאה**

**תוצאה צפויה:** ההפרדה לפי מרפאה נאכפת — אין גישה למטופלים/רופאים ממרפאה אחרת.

## 2. רופא (Doctor)

> התחברו כרופא: `amitperetz@gmail.com` / `Medsync123`.

### 2.1 תיעוד מפגש — ידני
**מטרה:** תיעוד ביקור ידני עם תלונות, מדדים, אבחנות ותרופות.

1. **מטופלים** → בחרו מטופל → **התחל ביקור**
2. מלאו **תלונות המטופל** (למשל: "כאב ראש, חום 38, עייפות")
3. מלאו **המלצות הרופא** ומדדים (לחץ דם `118/76`, חום `38.0`)
4. הוסיפו **אבחנה** מרשימת ICD‑10 והוסיפו **תרופה** (מינון/תדירות/משך) → **הוסף תרופה**
5. לחצו **שמור ואשר**

**תוצאה צפויה:** הביקור נשמר, הודעת הצלחה, מעבר חזרה. (שמירה ריקה → הודעת שגיאה על שדות חובה.)

### 2.2 תיעוד מפגש — עם הקלטה (AI)
**מטרה:** הדגמת התמלול והפקת סיכום אוטומטי מהדיבור.

1. פתחו ביקור חדש → לחצו על כפתור **המיקרופון** ודברו (תלונות + תרופות)
2. עצרו את ההקלטה והמתינו לעיבוד

**תוצאה צפויה:**
- שדות התלונות/ההמלצות מתמלאים אוטומטית מהתמלול
- **תרופות** שהוזכרו מתווספות אוטומטית לרשימה
- ניתן לערוך לפני שמירה
> אבחנות אינן מתווספות אוטומטית — נבחרות ידנית מרשימת ICD‑10 הסגורה.

### 2.3 עדכון מיידי של הסיכום הרפואי בבינה מלאכותית
**מטרה:** להראות שהסיכום הרפואי (AI) מתעדכן מיד עם נתוני המפגש שנשמר.

1. שמרו ביקור חדש (מ‑2.1 או 2.2)
2. חזרו לכרטיס המטופל וצפו ב**סיכום רפואי בבינה מלאכותית**

**תוצאה צפויה:** הסיכום כולל את המידע מהביקור החדש (תלונות/אבחנות/תרופות) — עודכן מיד.

### 2.4 העלאת מסמך עבור המטופל
**מטרה:** רופא מעלה מסמך רפואי לתיק המטופל.

1. בכרטיס המטופל → אזור **מסמכים** → **העלאת מסמך**
2. בחרו קובץ (או צלמו במצלמה), בחרו סוג מסמך → אישור

**תוצאה צפויה:** פס התקדמות ואז הודעת הצלחה; המסמך מופיע ברשימה.

### 2.5 צפייה בסיכום שנוצר עבור המסמך
**מטרה:** להראות את הפענוח/סיכום ה‑AI של המסמך שהועלה.

1. לחצו על המסמך → **צפה בסיכום**

**תוצאה צפויה:** נפתח חלון עם **סיכום המסמך בעברית** שהופק אוטומטית, עם אפשרות הורדה.

### 2.6 יצירת מפגש מתוך תור נוכחי
**מטרה:** לפתוח ביקור ישירות מתור מתוכנן להיום.

1. **תורים** (יומן המטפל) → בחרו תור של **היום**
2. לחצו על התור — המערכת פותחת את כרטיס המטופל עם הקשר התור (`slotId`)
3. **התחל ביקור** → תעדו ושמרו

**תוצאה צפויה:** הביקור נפתח מתוך התור. (ניתן לפתוח ביקור רק בתורים של **היום**.)

### 2.7 התראות קליניות — ידני + אוטומטי
**מטרה:** להוסיף התראה קלינית ידנית ולהראות התראות שנגזרות אוטומטית מהמפגשים.

1. בכרטיס המטופל, באזור **התראות קליניות**, לחצו **הוסף התראה**
2. הזינו שם התראה, בחרו **חומרה** (HIGH/…) ו**קטגוריה** (אלרגיה/…) → שמירה
3. הראו שהתראה מסומנת כ־**MANUAL**
4. הראו שהתראות נוספות נוצרו **אוטומטית** מתוך נתוני הביקורים (אלרגיות/מחלות כרוניות)

**תוצאה צפויה:** ההתראה הידנית מתווספת; לצידה מוצגות התראות אוטומטיות שנגזרו מהמפגשים.

## 3. מטופל (Patient)

> התנתקו והתחברו כמטופל: `keren1@gmail.com` / `Medsync123`.

### 3.1 העלאת מסמך
1. **מסמכים** → **העלאת מסמך** → בחרו קובץ, בחרו סוג → אישור

**תוצאה צפויה:** המסמך מועלה ומופיע ברשימה; לאחר עיבוד ה‑AI סטטוסו הופך ל"נותח".

### 3.2 הורדת סיכום ביקור
**מטרה:** להוריד PDF של סיכום ביקור.

1. בדשבורד/רשימת הביקורים, ליד ביקור, לחצו על **הורדת סיכום** (אייקון הורדה)

**תוצאה צפויה:** נוצר ומורד קובץ **PDF** עם סיכום הביקור.

### 3.3 צפייה במסמכים ובפענוחים
1. **מסמכים** → סננו לפי סוג → לחצו על מסמך לצפייה בפענוח/סיכום ה‑AI

**תוצאה צפויה:** רשת המסמכים מסוננת; חלון הסיכום/הפענוח נפתח.

### 3.4 צפייה בסיכום בינה מלאכותית
1. במסך **בית** צפו ב**סיכום בריאות בבינה מלאכותית** (מחלות כרוניות, היסטוריה, דגשים)

**תוצאה צפויה:** מוצג סיכום בריאות אישי שהופק אוטומטית.

### 3.5 מסך "התורים שלי"
1. **התורים שלי** → עברו בין הלשוניות (קרובים / עברו / בוטלו)
2. בתור קרוב לחצו **ביטול תור** → אישור

**תוצאה צפויה:** התור עובר ללשונית **בוטלו**.

## 4. מזכירה (Secretary)

> התנתקו והתחברו כמזכירה: `hodaya1@gmail.com` / `Medsync123`.

### 4.1 הוספת תורים למטופלים (אשף 3 שלבים)
1. **קביעת תור** → **שלב 1:** בחרו מטפל → **שלב 2:** בחרו מטופל → **שלב 3:** בחרו תאריך ושעה פנויה
2. (אופציונלי) סמנו **הגיע עם הפניה** → אישור

**תוצאה צפויה:** חלון אישור הצלחה; התור נוצר.

### 4.2 צפייה בתורי הרופאים וסידורם
1. **תורי המרפאה** → עברו בין הלשוניות (קרובים / עברו / בוטלו)
2. הראו את תורי הרופאים במרפאה; בטלו תור קרוב (**ביטול תור** → אישור)

**תוצאה צפויה:** מוצגים תורי הרופאים במרפאה; תור שבוטל עובר ללשונית **בוטלו**.

### 4.3 העלאת מסמכים עבור מטופלים
1. **מסמכים** → בחרו מטופל → העלו קובץ (או צלמו), בחרו סוג → אישור

**תוצאה צפויה:** פס התקדמות ואז הודעת הצלחה.

## 5. אדמין (Admin)

> התנתקו והתחברו כאדמין: `amitadmin@gmail.com` / (סיסמה נכונה — ראו אזהרה בסעיף 0).

### 5.1 ניהול משתמשים (הוספה / עריכה / מחיקה)
1. לשונית **משתמשים** → הראו את הטבלה
2. **הוספת משתמש** (מלאו פרטים ותפקיד) → שמירה
3. **עריכת** משתמש קיים → שמירה
4. **מחיקת** משתמש → אישור

**תוצאה צפויה:** המשתמש נוסף/מתעדכן/נמחק מהטבלה בהתאם.

### 5.2 הוספת מרפאה
1. לשונית **מרפאות** → **הוספת מרפאה** → מלאו פרטים → שמירה

**תוצאה צפויה:** המרפאה החדשה מופיעה ברשימת המרפאות.
